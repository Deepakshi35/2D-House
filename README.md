2D House Drawing with Colour Filling using OpenGL

Project Description

This project demonstrates a simple 2D house drawing using OpenGL. It uses different shapes and colours to create a house with a roof, windows, door, sun, garden and pathway.

Features

- 2D house drawing using OpenGL
- Colour-filled house walls and roof
- Windows and main door
- Sun and green ground
- Simple garden and pathway
- Basic geometric shapes

Technologies Used

- C++
- OpenGL
- FreeGLUT
- Visual Studio Code
- MSYS2

How to Run

Compile the program:

g++ main.cpp -o house.exe -lfreeglut -lopengl32 -lglu32

Run the program:

./house.exe
